# Singular Value Decomposition (SVD)

A practical exploration of **Singular Value Decomposition (SVD)** using Python and Jupyter Notebook.

This repository demonstrates the mathematical concept of SVD through an interactive notebook, including matrix decomposition, singular values, singular vectors, and related numerical computations.

## 📌 Overview

**Singular Value Decomposition (SVD)** is one of the most important matrix factorization techniques in linear algebra and numerical computing.

For a matrix **A**, SVD decomposes it into three matrices:

### A = UΣV<sup>T</sup>

where:

- **U** — Left singular vectors
- **Σ** — Diagonal matrix containing the singular values
- **V<sup>T</sup>** — Transpose of the right singular-vector matrix

The singular values are conventionally ordered from largest to smallest:

### σ<sub>1</sub> ≥ σ<sub>2</sub> ≥ ⋯ ≥ σ<sub>r</sub> ≥ 0

SVD is widely used in:

- Dimensionality reduction
- Data analysis
- Image processing
- Machine learning
- Signal processing
- Numerical linear algebra
